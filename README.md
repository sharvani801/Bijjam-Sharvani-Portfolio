# Bijjam Sharvani Portfolio — React + Vite

## Open in VS Code
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite (usually http://localhost:5173).

## Build
```bash
npm run build
```

The original portfolio design, CSS, interactions, project filters, theme switcher, navigation, contact form, and resume link are preserved.
